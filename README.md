# Скупка ноут — сайт skupka-nout.by
Живой сайт: https://skupka-nout.by

Статический сайт скупки ноутбуков, компьютеров, смартфонов, планшетов и комплектующих в Минске (две точки: ул. Уманская, 53 и проспект Пушкина, 67). Есть калькулятор ориентировочной цены выкупа и отдельные страницы для 35 городов Беларуси.

## Структура

- `index.html` — главная страница (Минск)
- `style.css`, `seo.css` — стили
- `script.js` — плавная прокрутка по якорным ссылкам
- `calculator.js` — калькулятор ориентировочной цены выкупа
- `assets/` — логотипы и favicon
- `<город>/index.html` — страницы городов (например, `bereza/`, `gorki/`, `zhodino/`, `vileyka/`), всего 35 папок
- `robots.txt`, `sitemap.xml` — для поисковых систем

## Как открыть

Сборка не нужна: откройте `index.html` в браузере. Для проверки страниц городов удобнее локальный сервер:

```
python -m http.server 8000
```

и адрес http://localhost:8000/.
